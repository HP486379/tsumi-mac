# 通常・実寸モードの構成確認

> この文書は `remove-tetris-mode` 時点の履歴です。現行の3モード構成は [最多積載台数チャレンジのレポート](../max-stack-count/README.md) を参照してください。

基準コミット: `419a56fc7870a6647ed678b79a46d80f7711c4e1`。検証日: 2026-10-29。

対応するゲームは通常モード（360×648px）と実寸モード（540×900px）の2種類。タイトルの他のゲーム選択肢、使われなくなった専用エンジン・配置/消去/記録処理・UI・スタイル・テスト・スクリプト・資料を除去した。ルールや筐体の変更はない。

共用レンダラーから、削除した機能だけが使っていた配置ゴースト・部分区間表示・グリッド切替用API/型を整理した。通常・実寸のグリッド、落下ガイド、行消しフラッシュ、断片描画、深度処理、正面/斜め同期は維持している。透明ボタンの共用スタイルなど、名前が似ていても両モードで必要な処理は残した。

## 保護対象

寸法表、通常miniの薄型M1/M2・転用M4、実寸の全6機種、盤面、Matter.js、GameSim/GameEngine、行消し、入力、スコア・保存処理は基準コミットとソースが同一。データ移行やブラウザー内記録の削除処理は追加していない。

通常・実寸・設定の既存キーはそのまま使用する。保存済みの他モードのキーは読み書きしない。検証では `ARCHIVED_RECORD_KEY` に過去の専用記録キーを渡し、両モードの起動・操作・ゲームオーバー・結果保存・タイトル復帰までStorage APIを監視。アクセス先は現行2種のハイスコアと設定の3キーのみで、旧記録の読み書き/削除は0回、既存の値はバイト単位で保持された。

## 検証結果

- `npm test`: 17ファイル、**269件すべて合格**。専用テスト34件を削除し、通常・実寸の既存テストは維持。
- `npm run build`: TypeScript / Vite本番ビルド成功。
- Playwright: 本番ビルドにPC Chrome/Pixel 7相当で接続し、**29件合格、11件は端末条件による対象外スキップ、失敗0**。メニューがゲーム2種類と遊び方だけであること、両モードのキーボード/タッチ操作・回転・落下・接地・行消し・ゲームオーバー・記録保持を確認。WebGL/Canvasの既存検証も実行した。
- `e2e/supported-modes.spec.ts`: 追加4ケースが全件合格。両モード×PC/スマホのタイトル・操作・記録隔離を検証。アーカイブキーは環境変数で指定でき、特定の過去モードへのコード依存を持たない。
- 削除前後で**6機種×2モード×2描画方式=24ケース**のメッシュ・正面PNG・斜めPNGを比較。SHA-256 **72項目すべて一致**。背景・グリッドもPNG照合に含む。
- 通常mini各3台を700ステップ積層させた結果も、全座標・回転・接触誤差・残存台数・スコアが削除前と完全一致。最大接触誤差は従来と同じ0.164px未満。実寸/他機種の寸法・接触・断片化は既存単体テスト/E2Eでも確認。
- 本番JavaScriptは416.23kBから395.46kBへ、CSSは12.11kBから11.63kBへ減少（Vite表示値、未gzip）。
- 廃止機能の名称・識別子を現行ソース、テスト、スクリプト、資料、本番distで検索して0件。専用ファイル名も現行の管理対象からすべて除去。過去のGit履歴と既存ブランチは保持する。

全モデルのハッシュ・寸法・接触座標は [rendering-audit.json](rendering-audit.json)。実画面と生の検証データは納品先 `outputs/mode-removal` に保存。

## 再現と制約

`npm test`、`npm run build`、`npm run test:e2e` を使用する。保存監視には必要に応じて `ARCHIVED_RECORD_KEY` を指定する。実施環境では `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` に既存Chromiumを指定し、4183の本番previewへ接続する外部設定（出力先とURLのみ変更）でE2Eを実行した。

描画比較は4173のVite開発サーバーを使い、基準コミットと変更後で `scripts/capture-classic-minis.mjs` をそれぞれ `baseline` / `removed` ラベルで実行。各ラベルを `FORCE_SOFTWARE=1` でも取得し、`MODE_AUDIT_OUTPUT` をそのフォルダーにして `node scripts/verify-rendering-unchanged.mjs` を実行する。

スマホはPixel 7エミュレーションで、実機Safariの検証は含まない。既知の新規不具合は確認されていない。ブラウザーに残る廃止モードの記録は、アプリから表示・更新できない。
