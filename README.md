# 積みMac — STACK YOUR MAC 🍎

**買って満足。積んで絶望。**

Mac風の架空デバイスを積み上げる、**2D物理演算 × 落ち物パズル**。重さ・摩擦・重心で積み方が変わり、列を揃えると「資産整理」が発動します。

## ゲームの特徴
- 落下・衝突・傾斜・崩壊を2D物理演算で表現
- 機器の大きさと重量が異なる5種類のブロック
- 10列×18行の仮想グリッドで列消しを判定
- 散財総額・整理額・積みMac指数を記録
- PC・スマホ両対応、N100クラスのPCでも遊べる軽量設計
